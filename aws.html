ПРО ПРОГРАМУ

Готова навчальна програма від AWS

AWS Academy надає закладам вищої освіти безкоштовну, повністю готову до викладання навчальну програму з хмарних обчислень. Курси розробляються AWS і регулярно оновлюються, щоб відповідати актуальному стану хмарних технологій.

Студенти отримують практичний досвід у пісочниці AWS Academy Learner Lab з доступом до понад 100 сервісів AWS, а також безкоштовну 12-місячну підписку на AWS Skill Builder і доступ до спільноти Emerging Talent Community після завершення курсу.

НАВЧАЛЬНА ПРОГРАМА

Курси AWS Academy

Від базових концепцій хмари до архітектури, розробки, ML і роботи з даними.

Foundational

Cloud Foundations

Вступний курс з огляду хмарних обчислень: основні сервіси AWS, безпека, архітектура, ціноутворення та підтримка.

Foundational

Generative AI Foundations

Вступ до штучного інтелекту з акцентом на генеративний ШІ та його застосування в хмарних обчисленнях.

Foundational

Machine Learning Foundations

Основи ML: вибір, навчання й розгортання власної моделі. Близько 20 годин лекцій, лабораторних робіт і проєктів.

Foundational

Data Center Technician (DCT)

Технічна експертиза в експлуатації дата-центрів; бажані базові знання з механіки й електротехніки.

Foundational

Engineering Operations Technicians

Основи фізичної інфраструктури дата-центру: електрика, батареї та генератори.

Foundational

Cloud Security Foundations

Базові принципи кібербезпеки для хмарних обчислень через практичні сценарії й демонстрації.

Associate

~40 год · рекомендовано після Cloud Foundations
Associate

Cloud Operations

DevOps і cloud-ops ролі: автоматизація розгортання мереж і систем. Підготовка до AWS Certified SysOps Administrator – Associate.

~40 год · рекомендовано після Cloud Foundations
Associate

Data Engineering

Збір, зберігання, підготовка, аналіз і візуалізація даних для аналітики й задач машинного навчання.

Associate

ML for Natural Language Processing

Термінологія та застосування обробки природної мови (NLP) для розв'язання бізнес-задач.

ПОЧАТИ НАВЧАННЯ

Як приєднатися

Членство в AWS Academy оформлюється на рівні закладу освіти — окремої форми реєстрації студента на цьому сайті не потрібно.

1

Перевір відповідність критеріям

Заклад повинен пропонувати акредитовані освітні програми (диплом, сертифікат чи курси підвищення кваліфікації).

  • Заявник — уповноважений викладач або адміністратор програми від закладу
  • Заявку подають з інституційної електронної пошти
2

Подай заявку від імені закладу

Institution Application подає Program Administrator — особа, відповідальна за адміністрування програми AWS Academy в закладі.

Подати заявку на сайті AWS Academy →

3

Почни навчання

Після схвалення заявки заклад приймає умови програми, призначає викладачів AWS Academy курсів і пропонує план проведення занять.
